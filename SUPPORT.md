# PureWall Support

PureWall is an open-source Windows desktop project. Choose the channel that matches the kind of help you need.

## Usage and setup questions

Use [GitHub Discussions](https://github.com/WiseZenn/PureWall/discussions) for installation questions, local builds, supported library paths, configuration, and general usage. Search existing discussions first and include your Windows version plus PureWall version or commit.

## Reproducible bugs

Use the [bug report form](https://github.com/WiseZenn/PureWall/issues/new?template=bug.yml) when behavior can be reproduced. Include the smallest reproduction, expected and actual behavior, and relevant logs. Redact user names, personal paths, wallpaper file names, and other private content before posting.

## Security and destructive-behavior reports

Use a [GitHub private security advisory](https://github.com/WiseZenn/PureWall/security/advisories/new) for vulnerabilities or suspected destructive behavior involving files, registry writes, installers or uninstallers, path traversal, command execution, IPC exposure, or updater/signature verification.

Do not place exploit details, secrets, private paths, or destructive test evidence in a public issue or discussion. See [SECURITY.md](SECURITY.md) for the reporting boundary.

## Project scope

Feature requests should improve an existing local PureWall workflow. PureWall-X, online wallpaper feeds, and premature shared-core extraction are deferred; see [ROADMAP.md](ROADMAP.md).

Support is provided by project contributors on a best-effort basis. Public discussions and issues are not a guaranteed response channel or service-level agreement.
